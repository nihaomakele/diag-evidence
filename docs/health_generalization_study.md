# 健康误报与跨型号泛化：第二轮实验

本轮检验保留幅值与更合适的简单分类器能否减少健康误报，并增加主动拒绝类别的协议。结果有局部改善，也有明显退步，因此候选保留为实验方案，**未替换固定基线，不适合实际诊断**。

## 先限定比较，再评测留出数据

训练仍只使用6205/6206的24条记录，6207的12条记录用于选择。六组候选为两种特征乘三种模型：原55维归一化形状特征；增加4个原始数值幅值特征的59维特征；各配类中心、C=1逻辑回归或256棵树/叶节点至少5个样本的随机森林。随机种子20261101，其他参数固定，未继续扩大搜索。

幅值单位未核实，增加的是本数据集的相对数值，不能解释成已校准物理量。标准化、模型训练均只用训练部分。选择依据依次为验证平衡准确率、健康误报、固定候选顺序；选择后不把验证集加入训练。

| 特征 / 分类器 | 验证准确率 | 验证健康误报 |
|---|---:|---:|
| 形状 / 类中心 | 16.67% | 98.96% |
| 形状 / 逻辑回归 | 21.88% | 96.88% |
| 形状 / 随机森林 | 46.35% | 6.25% |
| 形状加幅值 / 类中心 | 23.44% | 70.83% |
| 形状加幅值 / 逻辑回归 | 33.07% | 61.46% |
| 形状加幅值 / 随机森林（入选） | 48.18% | 0.00% |

健康误报减少，但其他故障分类仍差。不能仅凭健康误报0%认为模型可靠。

## 新留出与已见数据明确区分

6208此前已查看，标为探索性结果。新增6204从原[HUST v3数据](https://data.mendeley.com/datasets/cbv7jyx4p9/3)选取内圈、外圈、健康9条记录，另取IO/OB组合故障6条作契约外状态压力测试。许可仍为CC BY 4.0，作者和数据处理署名见DATA_PROVENANCE.md。

6204没有可用的纯滚动体故障，不能编造该类样本。其三类结果不能直接与四类结果比较；下表只在同一列中比较相同样本上的两种模型。

| 指标 | 已见6208，四类384窗 | 新增6204，三类288窗 |
|---|---:|---:|
| 固定基线准确率 | 67.19% | 27.78% |
| 入选候选准确率 | 29.95% | 83.33% |
| 固定基线健康误报 | 100.00% | 98.96% |
| 入选候选健康误报 | 79.17% | 0.00% |

这表明单一验证型号不足以选出稳定泛化的方案。不能挑选83.33%作为总体效果，也不能把所有进步归因于某一个新增特征。

初次读取发现OB402只有121,082点，不足32个4096点不重叠窗口；该次运行在新留出预测前停止。修正为每记录至多32窗，OB402取29窗，总组合故障窗口189个。保留原冻结选择和差异记录，修正前后模型、阈值与训练参数完全相同。没有填充短记录或根据测试结果改选候选。

模型与拒绝阈值在新留出预测前写入本地冻结文件。这是可复核的本地实验顺序，不是外部预注册，也不是不可篡改的证明。

## 拒绝实验没有达到目标

训练部分按整个轴承型号留出，计算最近特征距离，得到距离阈值候选；再用验证集选择距离与分数门槛。每类验证覆盖率须至少50%，防止靠拒绝全部健康样本获得漂亮指标。目标为验证已接受错误率至多10%。这些都是实验工程约定，没有统计风险或概率保证。

实际选中分数下限0.25、训练距离90%分位数；验证覆盖率100%，错误率51.82%，质量目标未达到。对6204已知三类未拒绝样本；对189个组合故障窗口也全部未拒绝。该启发式未显示未知/组合故障检测能力。6208只拒绝6个窗口，覆盖率98.44%，接受错误率69.84%，同样不可靠。

分类器门槛的“接受”与主工作流结论强度分开。工作流原0.5分数规则、参考检查仍然生效，本实验没有为了提高覆盖率放宽它们。

## 接口改进：主动拒绝不再伪装成模型未加载

策略版本1.3增加：

```json
{"success": true, "diagnosis": {"abstained": true,
 "abstention_reason": "validation_quality_unmet", "predicted_class": null, "confidence": null}}
```

受支持原因还包括outside_training_support和below_selection_threshold。不得同时夹带类别、置信度或概率。适配器保留model_available=true，但给出no_conclusion；报告重新检查，旧成功记录不能恢复类别。服务不可用、健康预测、主动拒绝是不同状态。

实验StudyTransport要求显式提供验证质量门槛是否满足；本候选没有满足，所以接入时主动拒绝类别。即使其原始分数较高，也不形成类别报告。这个总质量门槛意味着覆盖率0、错误率无定义，**不能作为开放集识别成功或准确率提升的证据**。门槛声明本身没有认证或签名。

## 复现与文件

```bash
python -m pip install '.[study]'
python -m diag_evidence study-hust-health \
  --cache-dir artifacts/hust-data \
  --holdout-cache-dir artifacts/hust-6204 \
  --output-dir artifacts/health-study-1 --download
```

此命令要求cache-dir已有上一轮benchmark-hust取得的48条缓存；首次使用须先按real_data_benchmark.md运行该下载入口。study的--download只授权下载新增6204约96MB。输出目录须不存在，后续复现使用新目录。运行时先写protocol、validation_candidates和frozen_selection，再评测留出。trained_model包含训练参数；predictions保留每窗输出和拒绝原因；metrics报告全部结果；native_amplitude_audit供逐记录分析。基础安装不依赖scikit-learn，真实对照需要study扩展。

实现调用[LogisticRegression](https://scikit-learn.org/stable/modules/generated/sklearn.linear_model.LogisticRegression.html)和[RandomForestClassifier](https://scikit-learn.org/stable/modules/generated/sklearn.ensemble.RandomForestClassifier.html)。输出分数没有做独立概率校准；背景见[官方校准说明](https://scikit-learn.org/stable/modules/calibration.html)。

下一步应优先使用多个型号参与分组验证，分析逐类、逐记录错误；在固定方案后增加独立数据来源。当前63条记录仍来自同一实验台，窗口相关，也没有现场设备、完整物理身份或跨传感器验证。
