# DiagEvidence 已知限制

本地0.2.0.dev2提供可选历史参考声明适用性检查，仅涉及单位、采样率、可选预处理版本和时点。它不认证元信息、设备身份、工况或统计独立性，具体见[适用性说明](reference_applicability.md)。下述真实设备边界仍适用，时间字段比较不等于真实有效性验证。

- 当前是研究预览，核心规则阈值0.5、检索数量阈值3为工程约定，尚未通过真实设备验证或校准。
- 默认接受1024点振动窗口、50kHz；显式配置可改变窗口和采样率，外部模型是否兼容需另行确认。默认三类故障；显式bearing-health-v1加入健康类别3，但没有其他故障或分布外识别。不得用三类最高分推断设备一定故障，也不得将健康预测当作设备无故障证明。
- 候选标签一致不等于语义支持；返回条数不等于独立证据数。未检验真实设备、工况和通道适用性；可选历史参考检查只验证部分元信息声明与时间关系，不验证声明真实。
- 去重依赖服务的记录身份与内容；服务提供错误身份、同源改写文本或伪造标签仍可能绕过检查。
- 置信度由分类服务给出，未经概率校准。检索分数原样保留其声明，未知不转成相似度概率。
- 提示词泄漏为有限标记启发式检查。未命中不能证明无泄漏；模板流程标记为不适用。项目不调用LLM。
- 脱敏处理常见凭据形态和字段，不保证识别任意自由文本中的个人信息或业务秘密。产物是否可共享需依其实际内容判断。
- 网络调用有有限重试、总时间/响应字节预算，禁止重定向与压缩响应；这些是保守的客户端限制，可能拒绝原本可用的后端。进程最多4个活动HTTP工作线程，耗尽即失败。超时后底层DNS/套接字操作可能仍需等待返回，未实现远端取消、持久队列、认证管理或生产服务保障。自定义transport的网络行为由接入方负责。服务健康不代表分类能力。
- 同一Agent实例禁止并发，独立实例可并行。报告与运行记录没有事务式整体提交；部分写入失败会明确暴露。
- 自动化测试和合成场景未评价真实诊断准确率。新增[HUST实验](real_data_benchmark.md)仅评估固定实验台子集；测试健康误报100%，验证/测试型号表现差异显著，不能用于现场诊断。人工时间与元信息注入不代表部署事件。维修收益、无人平台决策、多智能体协作均未验证；本轮没有运行远程CI。
- 本版不含TimesFM推理依赖或权重；相关研究实验单独记录。数值预测不能直接当作故障概率、剩余寿命或决策收益。

- 0.2.0.dev2的[健康与泛化实验](health_generalization_study.md)结果不稳定；新增6204只有三类，不含滚动体，不能证明四类完整泛化。单一验证型号选择的方案在6208退步。当前距离拒绝未拒绝组合故障，不能声明具备开放集检测能力。
- 主动拒绝为接口状态，不是已验证的未知检测器。质量门槛是实验工程约定，不是统计置信保证或模型认证；门槛未达时全部拒绝只有零覆盖率，错误率无定义。

- 0.2.0.dev2按型号嵌套验证仍不稳定；所有HUST型号此前已看过，分组隔离不能消除前期探索带来的选择偏差。外部渥太华A条件全部被预测为健康，不能迁移部署。采样率/表示对齐不等于领域有效性，模型高分也没有跨来源概率保证。
- 外部JSON推理只解释固定数值参数，不执行pickle。参数与本地选择记录的SHA256用于一致性核对，不是模型认证、数字签名或独立验证证明。
