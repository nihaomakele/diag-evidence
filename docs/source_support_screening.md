# 源数据支持范围筛选与独立台架验证

0.2.0.dev4，2026-11-01。本轮增加按原始记录建立的距离筛选、完整决策记录和两套HIT-SM实验台评测。分类器沿用上一轮冻结的HUST形状特征逻辑回归，便于单独观察筛选规则的作用。

## 做法

1. 沿用4096点窗口和55维归一化特征。每条原始记录最多取32个非重叠窗口。
2. 在HUST四个型号间轮流留出一组。每轮仅用其余36条记录计算特征均值、标准差和每记录的特征中位数代表。
3. 查询窗口到最近记录代表的标准化欧氏距离作为支持距离。每条留出记录取窗口距离的最大值，共得到48个记录最大值。
4. 固定取升序第46个值作为阈值，结果为**14.70838461686537**。随后用全部48条源记录建立最终支持库，保留48个记录代表。
5. 对比三种接受规则：分类分数≥0.5、支持距离≤阈值、两者同时满足。记录级预测采用窗口多数票；记录级接受要求该记录全部窗口通过对应规则。

源数据共进行四次留型号拟合及一次全量重拟合。全量重拟合参数与已有冻结分类器完全相同。阈值和参数先冻结，再获取HIT-SM信号；源数据结果用于开发校准，新台架结果单独报告。

## 新台架与数据来源

[哈工大HIT-SM原始仓库](https://github.com/hitwzc/Bearing-datasets)提供自建实验台与SpectraQuest MFS两套数据，均为51.2kHz垂直振动。固定来源提交为`12e46cd1b4a40f396c2bd6e245be5bafe18b1989`，42文件共73,110,112字节。每台21条记录，覆盖600/900/1200rpm、健康及不同程度的内圈/外圈故障。

两台共1344窗，每台672窗。目标真类为内圈0、外圈1、健康3；分类器保留原来的四类输出，所有预测按目标真实标签计分。每台按21条原始记录汇总，窗口是同一记录中的相关观测。

原始仓库README明确允许将数据用于轴承故障状态分类，使用说明保留在[固定版本README](https://github.com/hitwzc/Bearing-datasets/blob/12e46cd1b4a40f396c2bd6e245be5bafe18b1989/README.md)。数据下载清单记录该声明，数据许可标识留空。源码采用MIT；数据按上游说明获取，公开结果保留机构、来源和处理记录。关联论文DOI为[10.1088/1361-6501/ac7941](https://doi.org/10.1088/1361-6501/ac7941)。

## 记录级结果

“接受错误数”指接受的记录中分类错误的数量；“接受错误率”的分母为接受记录数。

| 台架 | 规则 | 接受记录 / 全部 | 接受错误数 | 接受错误率 |
|---|---|---:|---:|---:|
| 自建 | 全部输出 | 21 / 21 | 18 | 85.71% |
| 自建 | 仅分数 | 20 / 21 | 17 | 85.00% |
| 自建 | 仅支持距离 | 14 / 21 | 11 | 78.57% |
| 自建 | 两者同时 | 13 / 21 | 10 | 76.92% |
| MFS | 全部输出 | 21 / 21 | 20 | 95.24% |
| MFS | 仅分数 | 15 / 21 | 15 | 100.00% |
| MFS | 仅支持距离 | 13 / 21 | 12 | 92.31% |
| MFS | 两者同时 | 8 / 21 | 8 | 100.00% |

自建台架的支持距离规则比单独分数规则少接受6条错误记录，并保留了3条正确记录。MFS上，支持距离保留了唯一正确记录；叠加分数条件后，这条正确记录也被筛掉。两种规则应同时比较保留量和错误数。

本轮选择：保留距离筛选作为可复现对照，默认方案继续沿用既有配置。后续优先开展新设备上的小规模带标签验证与模型适配，把分类器迁移能力和接受规则分别评估。下一次方法调整时，HIT-SM归入已见开发数据，再预留新的检验数据。

[机器可读结果](results/support_screening_20261101.json)包含源校准、两台架混淆矩阵、每类覆盖率、逐记录接受情况及冻结摘要。研究命令保存原始预测、支持距离、最近源记录和各规则的接受状态；现有服务流程继续使用既有质量门槛。

## 运行

从源码安装`python -m pip install ".[study]"`，使用已校验HUST缓存和分组实验生成的`external_model.json`、`external_selection.json`：

```bash
diag-evidence study-support --cache-dir artifacts/data/hust --model-dir artifacts/groups --output-dir artifacts/support
python scripts/download_hit.py --cache-dir artifacts/data/hit
diag-evidence evaluate-hit --selection-dir artifacts/support --cache-dir artifacts/data/hit --output-dir artifacts/hit-support
```

源缓存与分组实验的准备见[分组验证说明](grouped_and_external_validation.md)。`evaluate-hit --download`也支持从原始文件链接获取；备用脚本使用公开Git blob API，核对来源提交清单中的字节数与Git blob SHA后写入缓存，同时记录观测SHA256。每次评测使用新输出目录，下载缓存可复用。

首次原始链接连接超时，随后通过公开文件接口补齐缓存；冻结特征、分类器、距离方法及阈值保持原值。所有42文件在解析前均完成摘要核对。输入读取规则要求恰有一个真实数值振动向量，排除MAT内部字段和标量元数据。

本地已执行308项回归，其中本轮新增20项，覆盖记录代表、校准粒度、接受边界、异常输入及MAT布局。独立26项检查重算文件摘要、分组关系、阈值、窗口和错误计数。依赖环境沿用Python 3.12.14、NumPy 2.5.4、SciPy 1.18.1、scikit-learn 1.9.1；源码外安装复现另行比对冻结参数和逐窗输出。
