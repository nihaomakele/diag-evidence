# DiagEvidence 固定诊断流程说明

版本：v0.1.1；规则版本：diagnosis-evidence/1.0。

这是 `diag_evidence` 随包分发的业务流程文档，不是自动加载的 Codex 技能。安装本地源码或 wheel 后，通过 `diag-evidence demo` 运行合成演示；配置前缀为 `DIAG_EVIDENCE_`。

1. 在任何网络调用前验证1024点一维有限数值、信号质量并分析特征。
2. 可选探测后端可达性；可达不代表具备分类能力。
3. 获取历史候选与分类结果，验证各自响应契约。
4. 检查模型可用、类别映射、置信度、候选标签一致性、标签匹配、候选条数和提示词状态。
5. 将每项标记为passed/failed/unknown/not_applicable；必需项未知不允许最高支持等级。
6. 报告独立复验，实际强度取请求强度与规则上限的较低值。
7. 按配置保存独立运行编号的报告、轨迹和审计；写入失败在返回结果中明确暴露。

high仅指规则通过，候选标签多样性不等于语义矛盾，条数不代表独立证据。合成输入须明确标识。服务响应不能替代真实设备验证，详见根目录README与docs/policy.md。
