# 分组验证与独立来源检验

0.2.0.dev2增加两种可复现评测：嵌套按轴承型号留出，以及冻结模型后的跨来源检验。它们检验评测流程和泛化边界，**没有获得可部署的诊断模型，也未替换原固定基线**。

## 分组方法：测试型号不参与自己的选型

使用HUST v3已有48条记录、1536个窗口，四种型号6205/6206/6207/6208。所有这些型号此前都已查看，因此本轮仍是探索性复核，不能重新称为第一次盲测。

每次留一个型号作外层测试，其余三个型号内部再轮流验证。例如外层测试6208时：

1. 用6205/6206训练、6207验证；6205/6207训练、6206验证；6206/6207训练、6205验证。
2. 六个固定候选分别取得三个验证型号的结果。优先选择最差型号平衡准确率较高者，再比较平均准确率、健康误报和固定顺序。
3. 将选择写入冻结文件，再用全部三个外层训练型号重训。
4. 最后计算6208结果。其标签和预测结果不回流到本次内层选择。

共四个外层划分、每个三个内层验证。每个窗口作为所选模型的外层测试恰好一次；同一原始记录、同一型号不会跨该次训练/验证/测试角色。特征标准化也在每次拟合的训练部分重新学习。与方法相关的背景见[官方嵌套交叉验证说明](https://scikit-learn.org/stable/auto_examples/model_selection/plot_nested_cross_validation_iris.html)和[按组留出](https://scikit-learn.org/stable/modules/generated/sklearn.model_selection.LeaveOneGroupOut.html)。

候选仍为原来的两种特征乘三种模型，没有扩大搜索。未重新调节分数阈值，0.5仅作固定工程对照，不是校准概率。

## 分组结果：平均表现和最差型号都报告

| 外层测试型号 | 内层选择的候选 | 外层准确率 |
|---|---|---:|
| 6205 | 形状加幅值 / 逻辑回归 | 70.83% |
| 6206 | 形状加幅值 / 随机森林 | 55.21% |
| 6207 | 形状加幅值 / 逻辑回归 | 49.74% |
| 6208 | 归一化形状 / 随机森林 | 24.74% |

以下固定方法均在相同外层训练数据上拟合，不能把它们的数字与此前只用两个型号训练的结果直接混比。

| 外层方法 | 平均型号准确率 | 最差型号准确率 | 平均健康误报 |
|---|---:|---:|---:|
| 嵌套内层选型 | 50.13% | 24.74% | 21.09% |
| 固定归一化类中心 | 46.81% | 11.46% | 50.26% |
| 固定上一轮幅值随机森林 | 43.49% | 32.03% | 13.54% |

内层选型提高了本次平均值，但其最差外层结果仍低于固定随机森林。优化内层最差表现并不保证外层最差表现改善。四个型号来自同一实验台，窗口在记录内相关，不据此计算独立设备置信区间，也不宣称统计显著改进。

## 独立来源：先冻结，后读取目标数据

外部数据为Huan Huang、Natalie Baddour的[渥太华大学轴承数据v2](https://data.mendeley.com/datasets/v43hmbwxpm/2)，DOI 10.17632/v43hmbwxpm.2，[CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)。固定选择升速A条件的全部三个重复试验：健康、内圈、外圈、滚动体各三条，另加组合故障三条。共15文件、200,996,750字节。仅该条件被检验，不代表全部60条数据或所有速度条件。

2018年[原论文](https://pmc.ncbi.nlm.nih.gov/articles/PMC6249544/)描述的是早期36记录，v2发布目录扩展到60记录并加入滚动体及组合状态；标签和文件范围依据固定v2目录，不能混用两个版本的计数。

外部模型只在三个归一化形状候选中选择，避免把未核实单位的原始幅值直接跨传感器迁移。选择依据四个HUST开发型号的留型结果，随后在全部四个型号重训。这一步属于为外部检验选择开发模型，**其被选中的开发分数不当作无偏效果估计**。

冻结得到形状逻辑回归，包括训练均值、标准差、系数、来源和参数SHA256。冻结文件先于目标数据下载，目标标签不参与拟合、归一化统计或阈值选择。推理解释数值JSON参数，不加载pickle或执行模型文件中的代码。选中模型的JSON概率与原库计算在1e-12容差内一致。

目标数据原采样率200,000 Hz。只用振动Channel_1，未用转速编码Channel_2；先以32/125比例、固定Kaiser滤波器进行抗混叠重采样到51,200 Hz，再均匀取32个不重叠4096点窗口，使用去均值/RMS的无量纲形状特征。该处理对齐表示格式，不会自动消除传感器、轴承结构、转速或采集链差异。原幅值单位与真实采集时间保持未核实。

## 外部结果：全部预测为健康

12条已知状态记录产生384个窗口，四类各96。结果混淆矩阵为：

| 真实状态 | 预测内圈 | 预测外圈 | 预测滚动体 | 预测健康 |
|---|---:|---:|---:|---:|
| 内圈 | 0 | 0 | 0 | 96 |
| 外圈 | 0 | 0 | 0 | 96 |
| 滚动体 | 0 | 0 | 0 | 96 |
| 健康 | 0 | 0 | 0 | 96 |

准确率25%，故障被判健康的比例100%。所有已知窗口都通过0.5分数阈值，已输出错误率75%。虽然健康误报为0%，这是全部判健康造成的，不能解释为模型有效。另96个组合故障窗口也全部通过分数阈值，未显示未知/组合状态拒绝能力。

模型在目标数据加载前已未通过HUST多型号质量门槛。质量门槛限制后，类别覆盖率为0、已输出错误率无定义；这只验证声明门槛限制结论的行为，不能称为模型正确识别了分布外状态。实际渥太华信号接入完整工作流后，模型仍可用，但主动拒绝类别，报告不将拒绝转成健康。

该负面结果说明：格式有效、采样率一致、输入归一化、分类分数较高，仍不足以证明跨来源适用性。当前工程规则不能代替真实模型验证，也不认证元信息。

## 复现

先按real_data_benchmark.md准备HUST的48条缓存，再执行：

```bash
python -m pip install '.[study]'
python -m diag_evidence study-hust-groups \
  --cache-dir artifacts/hust-data --output-dir artifacts/grouped-run-1
python -m diag_evidence evaluate-ottawa \
  --selection-dir artifacts/grouped-run-1 \
  --cache-dir artifacts/ottawa-data \
  --output-dir artifacts/ottawa-run-1 --download
```

输出目录须尚不存在，保留缓存后可用新输出目录离线复现。外部推理只需benchmark扩展的SciPy及基础依赖，不要求scikit-learn；模型开发阶段需要study扩展。

分组产物包括split_plan、各外层selection、outer_predictions、development_loto和external_selection/model。外部产物包括固定数据清单、重采样协议、逐窗口预测、逐记录结果和SHA256。原始波形不随源码分发；分享派生预测与参数时保留两份数据的作者、版本、CC BY 4.0链接及处理说明。

下一步应优先检查采集链、频带、轴频和轴承结构差异，并为拒绝方法设置真正独立的检验。A条件现在已经查看；B/C/D也不能在调参后再被不加区分地称为完全独立设备数据。任务仍是研究评测，尚无现场设备、维修收益或真实多智能体协同验证。
