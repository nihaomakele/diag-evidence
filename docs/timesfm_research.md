## 最小研究实验

Apple Silicon可使用官方MLX接口。实验必须真正加载3.0，记录代码和权重版本、输入、输出形状、有限值、冷启动与推理耗时；不能用替身、旧模型或仅API导入来声称复现。官方入口见[TimesFM示例](https://github.com/google-research/timesfm#apple-silicon-mlx-backend)。

本版核心安装、离线演示和校验评测均不触发模型下载。2026-10-18 已在 Apple arm64、16 GiB 内存的本机独立安装 TimesFM 3.0.2 与 MLX 0.32.4，完成真实 MLX GPU 算术检查，并取得官方模型配置。真实 checkpoint 权重下载超时，尝试结束时没有权重和任何预测输出，因此未完成 TimesFM 数值推理、形状验证或效果复现。这与本项目的12个合成契约场景是两项独立工作。

本次状态以本版 `VALIDATION.md` 为准。原始实验产物保存在维护者独立研究目录，不随发布包分发，也不能计入诊断效果。

## 下一步冻结回测协议（尚未执行）

这是本项目提出的自定义协议，不冒充任何论文标准切分。

| 项目 | 固定设置 |
|---|---|
| 数据 | [ETDataset官方ETTh1](https://github.com/zhouhaoyi/ETDataset)，目标OT |
| 任务 | 单变量温度数值预测；后续再独立比较多变量 |
| 上下文/预测步 | 512小时 / 24小时 |
| 划分 | 按时间60%训练、20%验证、20%测试；写出实际边界与摘要值 |
| 起点 | 每24小时滚动一次；预测目标完整位于当前划分内 |
| 处理 | 训练集统计量；验证集选规则后冻结；只用截至起点已观测历史 |
| 基线 | 最后值、24小时周期、真实TimesFM3单变量；多变量作为独立比较 |
| 指标 | MAE、RMSE；如有分位数，记录pinball loss、q0.1—q0.9覆盖率与宽度 |
| 成本 | 冷/热启动耗时、后端、依赖版本、内存条件和失败案例 |

测试历史前缀可以包含此前已经观测的测试点，不能包含预测区间真值；未来实测协变量不得进入模型。真值只供评分。ETT可能与基础模型预训练数据相关，不能无依据宣称严格未见分布或独立泛化。

分位数区间的覆盖是逐预测点统计，不等于整条路径联合覆盖。温度数值、区间宽度与模型输出不是故障概率、剩余寿命或无人系统任务决策；这些任务需要另外的目标标签与评价设计。

协议、数据授权和真实数值回测完成后，再设计ForecastRequest/ForecastResult以及与校验层的适配，避免在缺少数据时提前固定错误接口。多智能体协同作为更后续的任务，须补通信、观测和决策收益基线。
